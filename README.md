### 🚀 Featured Project: Team Task Manager

An interactive, real-time collaboration and project management board featuring live notifications and role-based permissions.

*   **Tech Stack**: React, Vite, Node.js, Express, Prisma, SQLite, and Vanilla CSS.
*   **Key Features**:
    *   ✔️ **Smart Task Grouping**: Automatically merges duplicate cards under multi-assignee task cards to prevent board clutter.
    *   ✔️ **Dynamic Notification Hub**: Instantly updates team members upon task assignment with automatic close on navigation.
    *   ✔️ **Polished Responsiveness**: Sleek glassmorphism style that adapts perfectly from desktop monitors to mobile displays.
*   **Repository**: [github.com/Viper8991/team-task-manager](https://github.com/Viper8991/team-task-manager)
